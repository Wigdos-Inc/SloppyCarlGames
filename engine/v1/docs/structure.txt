engine/
  v1/
    assets/ // Engine, studio, and character assets used by the runtime and test game
    Bootup.js // Initializes engine boot sequence and startup tasks
    credits.txt // Engine credits text

    core/
      config.js // Global engine configuration values (and settings application)
      ini.js // Initialize exportable ENGINE API for games.
      meta.js // Engine-wide utilities (functions, constants, APIs, etc)
      validate.js // Validation utilities for game payloads.
      normalize.js // Data normalization and alias resolution of validated game payloads for engine use.
      canonSchemas.json // Live canonical schema, aliases, normalization/validation metadata for payload fields. Shared fields are referenced by path; resolved at load by normalize.js.

    builder/
      NewBoss.js // Comment-only stub; bosses build through NewEntity.js as type "boss"
      NewEntity.js // Builder for generic entity model creation (anything that supports being animated)
      NewLevel.js // Builder for creating levels from incoming data (uses most other builders)
      NewObject.js // Builder of 3D meshes (mainly to be used by other builders)
      NewObstacle.js // Builder of obstacles
      NewPrimitive.js // Primitive shape geometry (cube, sphere, tube, ramps, ...); BuildGeometry, used by NewObject.js and NewScatter.js
      NewParticles.js // Resolves particle templates + per-call overrides into randomized particle-group entities (GenerateParticles)
      NewTemplate.js // Resolves shape:"template" references and repeat expansion for terrain/obstacle/entity builders
      NewTerrain.js // Terrain builder; BuildTerrain builds single-part objects and flattened multi-part composition
      NewScatter.js // Builds instanced scatter batches on top of terrain meshes and obstacle parts
      NewTexture.js // Procedurally generated texture mapping onto meshes.
      NewUI.js // Builder of UI components (mainly HTML elements)
      NewVoid.js // Builds void wall meshes and clips host surfaces to the void solid for openings (used by NewLevel.js)
      subProcesses/
        Chunks.js // Terrain surface chunks and collision chunks (the physics broadphase walks them)
        Loops.js // Loop surfaces and tube centerlines from the terrain chunk links
        Occlusion.js // Terrain blockers for occlusion culling, with void cuts
      templates/
        Instance.js // Boot-time Unit-instancing of engine-owned template JSON, plus game template registration
        characters.json // Character templates (shape:"template" refs of type "character")
        enemies.json // Enemy templates (shape:"template" refs of type "enemy")
        levels.json // Level and simulator template definitions
        obstacles.json // Obstacle templates (shape:"template" refs, terrain/obstacle role "obstacle")
        particles.json // Particle types (color/velocity/spread/duration/physics + a single part prototype); resolved by NewParticles.js
        projectiles.json // Projectile templates (shape:"template" refs of type "projectile")
        scatter.json // Scatter types (placement levers, scale range and parts)
        terrain.json // Terrain templates (shape:"template" refs, terrain/obstacle role "terrain")
        textures.json // Texture preset definitions

    handlers/
      Controls.js // Handles inputs from ui/level cache or sends inputs to game if unconsumed (input manager)
      Cutscene.js // Cutscene orchestration handler (cutscene manager)
      Render.js // Displays everything to the game (end of all visual pipelines)
      Sound.js // Sound manager and helpers (many exported)
      UI.js // UI handler (UI state manager)
      game/
        Animation.js // Level entity animation handler based on entity states
        Boss.js // Comment-only stub
        Collectible.js // Collectible item behavior
        Enemy.js // Enemy behavior handler
        Level.js // Level lifecycle and orchestration (entire level state manager)
        Performance.js // Per-instance physics/rendering distance flags, resolved once per tick
        Simulator.js // Simulator mode lifecycle and live scene preview orchestration
        Texture.js // Custom texture and sprite loading onto meshes. Includes animated texture handling.
      menu/
        Splash.js // Manages splash screens on game startup
        LoadScreen.js // Loading screen logic
        Credits.js // Credits screen UI/behavior
      utilities/
        Shaders.js // WebGL shader sources and program builders used by Render.js

    camera/
      Master.js // Level camera orchestrator: situation detection, set → mode, placement and obstruction
      Modes.js // Camera modes: orbitCam, freeCam, chaseCam, sideCam
      Sets.js // Resolves a level's camera config into its runtime set
      Sets.json // Mode, situation and addon catalogue plus built-in sets (carlCamSet)

    cutscene/
      Actors.js // Cutscene actor definitions, manager and helpers
      Animation.js // Cutscene-specific animation handler
      AudioSync.js // Sync audio with cutscene timelines (make sure audio plays at right time and speed)
      Scene.js // Cutscene scene management
      Master.js // Cutscene state manager.

    math/
      Collision.js // Collision math: narrowphase contacts, triangle grids and soups, overlap, sweep, ray and solid queries
      Curves.js // Easings, cubic-Bezier tube connector centerlines, and rotation-minimizing frames
      Forces.js // Pure gravity, buoyancy, resistance, deceleration and submergence math helpers
      Geometry.js // Triangle, box and collider-from-box geometry, polygon splitting, closest points and linked groups
      Matrix.js // 4x4 matrix creation and transform composition helpers
      Vector3.js // 3D vector math utilities
      Utilities.js // Utility math functions (includes Unit/UnitVector3 classes).

    physics/
      Collision.js // Collision detection utilities
      Correction.js // Surface classification, grounding derivation, and position/orientation correction
      Current.js // Movement adjustments while in underwater currents
      Forces.js // Engine-shaped force assembly for gravity, buoyancy, resistance, and submergence
      Master.js // Physics pipeline manager and orchestrator for moving entities

    player/
      Abilities.js // Comment-only stub
      Animation.js // Empty file
      Master.js // Player master controller (player state manager)
      Model.js // Assembles the player as an entity via builder/NewEntity.js from a characters.json template
      Movement.js // Movement handler for player
      characters.json // Player character presets

    docs/
      rules/ // Engine rule documents governing module structure and implementation constraints
      system_map/ // SAGE-maintained per-system reference documentation (one entry per module group)
      status/ // DEFERRED.md and AGENT_LOG.md
      changelog // Engine changes since the last docs update
      todo // Engine task notes
    testGame/ // Example/integration game used to exercise the engine API

Notes:
- Builders create 2D HTML elements and 3D WebGL2 meshes and are called by state managers.
- Helpers are state managers and helper functions to simplify pipeline.
  - Games are only allowed to interact with helpers accepting payloads (e.g. UI.js or Level.js).
  - Game payloads must first be validated and normalized through validate.js and normalize.js before the data is usable.
- Render.js is the only file allowed to display visual elements to the game.
